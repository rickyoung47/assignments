# 성수 상권 리포트

2026년 1분기 서울시 상권분석서비스 추정매출을 성수 네 행정동 지도와 업종별 그래프로 보여주는 정적 웹 앱입니다.

## 화면 기능

- 성수1가제1동, 성수1가제2동, 성수2가제1동, 성수2가제3동 행정동 경계 지도
- 최근 제공일(현재 데이터: 2026년 11월 18일)의 네 동 합산 시간대별 내국인 생활인구 그래프
- 지도에서 동을 고르면 해당 동의 전체 매출 상위 5개 업종 갱신
- 58개 서비스 업종 선택
- 전체 매출, 주중 매출, 주말 매출 탭
- 업종 및 매출 기준별 네 행정동 비교 그래프

매출 금액 단위는 원입니다. 서비스 업종별 API 결과를 앱의 정적 JSON 데이터로 포함하므로, 브라우저에 API 키가 전달되지 않습니다.

## 로컬에서 보기

이 디렉터리에서 정적 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 `http://localhost:8000`을 엽니다.

## 데이터

- 매출: [서울시 상권분석서비스(추정매출-행정동)](https://data.seoul.go.kr/dataList/OA-22175/S/1/datasetView.do), 2026년 1분기
- 생활인구: [[내국인] 행정동별 서울 생활인구(250m)](https://data.seoul.go.kr/dataList/OA-23016/S/1/datasetView.do), 2026년 11월 18일, 시간별 `SPOP`를 네 동 합산
- 행정동 경계: 서울 행정동 경계 자료에서 요청된 네 동만 추린 GeoJSON
- 화면의 매출 값은 카드 매출 기반 추정치이며, 공식 데이터의 원 단위를 표시합니다.
- 생활인구 자료 출처 표기: 서울특별시·KT, 서울시 통신데이터
